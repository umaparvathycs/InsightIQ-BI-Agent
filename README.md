# InsightIQ – AI-Assisted Business Intelligence Agent

<p align="center">
  <b>Transform Natural Language into Business Insights</b>
</p>

InsightIQ is an AI-powered Business Intelligence application that allows users to upload structured datasets and ask analytical questions using natural language. The system automatically generates SQL queries, retrieves data from PostgreSQL, creates interactive visualizations, and provides AI-generated business insights and recommendations.

## 🚀 Live Application

- **Frontend:** https://insightiq-bi-agent-1.onrender.com
- **Backend API:** https://insightiq-bi-agent.onrender.com
- **API Documentation:** https://insightiq-bi-agent.onrender.com/docs

## 📌 Project Overview

Traditional Business Intelligence tools often require users to understand SQL, database schemas, and data visualization techniques.

InsightIQ simplifies this process by integrating Large Language Models with database technologies.

Users can upload CSV or Excel datasets and ask questions such as:

- Which product generated the highest total sales?
- Compare total sales across different regions.
- Which product category performs best?
- Show the total revenue generated by each product.

The AI agent converts these questions into PostgreSQL queries and presents the results through tables, interactive charts, and business insights.

## ✨ Key Features

- **Dataset Upload:** Upload CSV and XLSX files.
- **AI-Powered Text-to-SQL:** Convert natural-language questions into SQL queries using Google Gemini.
- **Schema Retrieval:** Dynamically retrieve database table and column information.
- **LangGraph Workflow:** Coordinate SQL generation, validation, execution, and correction.
- **SQL Validation:** Validate generated SQL using SQLGlot.
- **PostgreSQL Database:** Store uploaded datasets using Neon PostgreSQL.
- **Interactive Visualization:** Generate charts using Plotly.
- **AI Business Insights:** Generate key findings, business interpretations, and recommendations.
- **Query Results:** Display SQL queries and corresponding results in an interactive dashboard.

## 🏗️ System Architecture

The application follows an AI-assisted business intelligence workflow:

1. User uploads a dataset through the frontend.
2. FastAPI receives the dataset and processes it using Pandas.
3. SQLAlchemy stores the dataset in Neon PostgreSQL.
4. User submits a natural-language analytical question.
5. The LangGraph agent coordinates the workflow.
6. Database schema information is retrieved.
7. Google Gemini generates a PostgreSQL query.
8. SQLGlot validates the generated query.
9. The SQL executor executes accepted queries using a read-only transaction.
10. Results are returned to the frontend.
11. Plotly generates interactive visualizations.
12. Google Gemini generates business insights and recommendations.

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/umaparvathycs/InsightIQ-BI-Agent.git
```

### 2. Navigate to the Project Directory

```bash
cd InsightIQ-BI-Agent
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

### 5. Configure Environment Variables

Create a `.env` file in the project root directory.

Add the following variables:

```env
GEMINI_API_KEY=your_gemini_api_key
DATABASE_URL=your_neon_postgresql_connection_string
```

Replace the example values with your own credentials.

**Important:** Never upload your `.env` file or API keys to GitHub.

### 6. Run the Backend

```bash
python -m uvicorn backend.main:app --reload
```

Backend URL:

```text
http://127.0.0.1:8000
```

API documentation:

```text
http://127.0.0.1:8000/docs
```

### 7. Run the Frontend

Open another terminal:

```bash
cd frontend
python -m http.server 5500
```

Open the application:

```text
http://127.0.0.1:5500/index.html
```

```sql

FROM sample_business_sales

LIMIT 1;
```

## 🔐 Security Considerations

- Generated SQL is parsed and validated using SQLGlot.
- The current validator restricts accepted statements to top-level SELECT queries.
- Database execution uses read-only transactions.
- Query results are limited to a bounded number of rows.
- API keys and database credentials are maintained through environment variables.

Further security hardening, including recursive SQL validation, stronger database permissions, authentication, and query timeouts, is required before production use.
